Buses Vigo

Cando chega o teu bus, dunha ollada. Proxecto persoal, sen relación con Vitrasa nin co Concello de Vigo.

De onde saen os datos

Os tempos de chegada veñen da API aberta do Concello de Vigo. As liñas, as paradas e os horarios, do GTFS oficial de Vitrasa, que se actualiza cada semana.

A posición de cada bus no mapa é unha estimación feita coa distancia que dá a API ata cada parada: non é o GPS do vehículo.

Os teus datos

As túas paradas e preferencias gárdanse só neste dispositivo. Se activas os avisos coa web pechada, a parada e a liña envíanse ao servidor de avisos só para avisarte, e bórranse despois.
